# BoomVoyage

Fireworks from around the world, every 2 minutes.

A single static web page. It draws a night harbour on a canvas and plays a
fireworks show about every two minutes, with sound made live in the browser.
The first stop is Sydney Harbour. More countries can be added one file at a time.

Plain HTML, CSS and JavaScript. No frameworks, no build step, no libraries,
and no image, audio, video or font files. Everything you see and hear is
generated by code.

## What it does

- Full-screen night scene: sky, stars, skyline, water with moving reflections.
- A fireworks show every 2 minutes, with a "Next show in m:ss" countdown.
- Every show is different: new colours, new middle acts, new timing.
- A bridge "waterfall" of sparks and a finale in every show.
- Sound for every launch, burst and crackle, plus a soft night ambience.
- Mute button (your choice is remembered), fullscreen button, "Launch now" button.
- Tap or click the sky to fire one shell of your own.
- A small caption names the act that is playing ("Act 2 of 6 · Willows").
- "Copy link" gives a link that opens the same harbour, colours and show.
- Ambient (TV) mode hides everything but the show and keeps the screen awake.
- Works on phones and tablets. Portrait screens get their own composition
  with both landmarks fully in view.
- Respects "reduce motion": gentler show, no flashing, no strobe.

Keys: `Space` launch a show, `M` mute, `F` fullscreen, `A` ambient mode, `Esc` leave ambient mode.

## Link options

Add these to the address of the page (after a `?`, joined with `&`).

| Option | Example | What it does |
|---|---|---|
| `scene` | `?scene=sydney` | Opens that harbour (the `id` of a scene file). |
| `seed` | `?seed=3735928559` | The first show is this exact show: same acts, same timing. A whole number from 0 to 4294967295. |
| `theme` | `?theme=ember-jade` | Uses that colour theme for the shared show. It is the theme name in lower case with dashes, for example `harbour-blue`. |
| `ambient` | `?ambient=1` | Starts in ambient (TV) mode. Also works with `true`, `yes`, `on`. Use `0` for off. |

Example: `https://<your-user-name>.github.io/boomvoyage/?scene=sydney&seed=1532556838&theme=harbour-blue`

- **Copy link** (the link button next to "Launch now") builds a link with
  `scene`, `seed` and `theme` of the show you just watched. The person who opens
  it sees the same show first. After that, shows are random as usual.
  The text "Link copied" appears for a moment. If the browser does not allow
  copying, a small box shows the link so you can copy it by hand.
- Options you add by hand can be mixed: `?scene=sydney&seed=42&ambient=1`.
- A wrong value (for example a seed that is not a number) is ignored. It never
  breaks the page. An unknown `scene` is ignored and no shared show is used.
- "Same show" holds for the same version of the site and the same
  reduce-motion setting (reduce motion swaps flashing bursts for calm ones).

### Ambient (TV) mode

Press the screen button next to "Copy link", press `A`, or open a link with
`?ambient=1`. All buttons, the countdown and the captions fade away, and the
mouse pointer is hidden. **Tap or click anywhere, or press `Esc`, to leave.**

- Browsers only allow sound after a tap, so a link with `?ambient=1` still
  shows "Tap to start" first. One tap, then the controls stay hidden.
- The screen is kept awake with the Screen Wake Lock API. Browsers without it
  (or that refuse it) get a best-effort fallback: a tiny silent video that
  some browsers treat as "something is playing". If neither works, nothing
  breaks, but the screen may dim; then set a longer screen timeout in the
  device settings. The lock is let go when you leave ambient mode.

## Run it

The page uses JavaScript modules, so it needs a small local web server.
Opening `index.html` by double-click will not work.

In PowerShell, inside the project folder:

```powershell
py -m http.server 8000
```

Then open http://localhost:8000 and press "Tap to start".

## Test it

The tests use the test runner that is built into Node.js (version 20 or newer).
Nothing to install.

```powershell
node --test
```

There are 54 tests in `tests/`:

- `schedule.test.js` — the 2-minute timing (background tabs, slow timers, "Launch now", the `m:ss` text).
- `show.test.js` — the show builder (same seed = same show, shows differ, missed cues are skipped, act names and their timing, same seed + theme = same show for share links).
- `scenes.test.js` — every scene file has what the engine needs.
- `link.test.js` — reading and building link options.
- `wakelock.test.js` — keeping the screen awake (API, fallback, tab hidden and shown again).

## Deploy to GitHub Pages

There is no build step, so GitHub can serve the repository as it is.

1. Merge the code into `main` on GitHub.
2. Open the repository on GitHub, then **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/ (root)**, then **Save**.
5. Wait about a minute. The site is at `https://<your-user-name>.github.io/boomvoyage/`.

All paths in the project are relative, so it works in that sub-folder.
The empty `.nojekyll` file tells GitHub Pages to serve the files unchanged.

## Add a country

A scene is one config object in one file.

1. Copy `js/scenes/sydney.js` to a new file, for example `js/scenes/tokyo.js`.
2. Change `id`, `name`, `country`, `tagline`, the `palette`, and the drawing
   functions (`drawSky`, `drawSkyline`, `drawWater`).
3. Change `show.palettes` (firework colours and their names) and, if you like,
   `sound` (reverb length, echo, boom pitch, ambience).
4. If the place has a bridge or a long roof line, return it from `rig()` as
   `waterfall` points. If not, remove `rig` and set `show.features` to `{}`;
   the show then skips the waterfall act.
   The captions use the act names in `js/show.js`; to rename one for a place,
   add `actLabels: { waterfall: 'Bridge of Light' }` to its `show` settings.
5. Add the file to `js/scenes/index.js`:

   ```js
   import sydney from './sydney.js';
   import tokyo from './tokyo.js';
   export const scenes = [sydney, tokyo];
   ```

The scene switcher, the start screen, the schedule and the sound pick it up
with no other change. Run `node --test` to check the new scene file.

Scenes draw in "scene units": x runs from -500 to 500 (0 is the middle) and
y goes up from the waterline. `v.px(x)` and `v.py(y)` turn units into pixels,
so one drawing fits every screen size.

## Creative decisions

### Design

- **A night postcard, not a photo.** The scene is flat, layered silhouettes,
  like a cut-paper travel poster. This style stays sharp on any screen, costs
  almost nothing to draw, and lets the fireworks be the brightest thing.
- **Colour.** Deep indigo sky that turns to warm plum at the horizon, where
  the city lights are. The only pale object is the Opera House, so the eye
  finds it first. The only accent colour in the UI is one warm "ember" gold.
- **The scene reacts to the show.** Each burst lights the sky in its own
  colour for a moment, and the sails and windows catch that light. Fireworks
  and skyline are mirrored in the water, and the water moves. The light is
  only ever added, never blended in a way that can darken, so the sky stays
  clean.
- **Small true details.** The Southern Cross and its two pointer stars are in
  the sky, there is a thin moon, a red beacon on top of the arch, and small
  boats waiting on the water.
- **The Opera House.** Drawn in code as two halls of pointed shells. The
  shells lean toward the harbour and get taller toward it, and each hall has
  one small shell that faces the land. The far hall is larger and a little
  greyer, so the near one stands out. Thin rib lines fan over each shell,
  the open ends are warm glass walls, and a small pair of shells (the
  restaurant) sits at the land end of a wide three-step podium.
- **Two compositions.** On wide screens the city, the Opera House and the
  bridge stand in a row. On tall phone screens the scene is re-arranged like
  the classic postcard: the whole bridge fills the width, the Opera House
  sits in front of its left side, and the city is a small far-away row
  behind the sails. Nothing is cut off, and about four fifths of the sky is
  left for the fireworks, which are drawn bigger and burst higher there.
- **Typography.** A high-contrast serif in italic (Bodoni / Didot family) for
  the name and the numbers, like an old travel poster, and small wide-spaced
  capitals for labels. These are system fonts, so no font file is downloaded.
- **Quiet UI.** A few small round controls only. They sit in the corners and
  dim after six seconds without input, so the show has the whole screen.
  On a phone they form two short rows at the bottom, under the thumb.
- **Act captions.** A small gold "Act 2 of 6" over the act name in the same
  italic serif, just above the controls. It fades out and in when the act
  changes, and does not dim with the controls, so a quiet glance always tells
  you where the show is. With reduced motion the words change at once.
- **Ambient mode.** For a screen on a wall: no buttons, no numbers, no
  captions, no pointer. Only a three-second hint ("tap or press Esc to
  leave") appears when you switch it on by hand.

### Show

- **Five parts, like a real display:** an opening of slow single shells,
  three middle acts, the quiet waterfall, a finale, and one last gold shell.
- **Different every time.** Each show picks one of six named colour themes
  (Ember & Jade, Harbour Blue, Jacaranda, Southern Gold, Coral Sea, Waratah)
  and three of seven middle acts, in random order. It never uses the same
  theme twice in a row. The theme name appears on screen as the show's title.
- **The waterfall is the calm in the middle.** Sparks pour from the bridge
  deck, starting in the centre and spreading out, while slow white shells
  float above. Then comets fan out from the arch. After that the finale
  feels bigger.
- **The finale gets faster,** from about two shells a second to about nine,
  then five gold willows fill the sky together, three white flashes, a short
  pause, and a single very large gold shell to end.
- **Length.** A show runs about 47 seconds, so there is more than a minute
  of quiet night before the next one.

### Sound

- **All synthesised.** A boom is three layers: a low sine "thump" that falls
  in pitch, a noise rumble that gets darker as it fades, and a very short
  sharp crack. Bigger shells are lower and longer.
- **Space.** Every sound goes through a long reverb and one clear echo, as if
  it came back from the far shore. Sounds are placed left or right to match
  where the shell is on screen.
- **Synced to the picture.** The sound engine does not keep its own timeline.
  The drawing code tells it "this shell opened now", so the boom starts on
  the same frame as the burst.
- **Restraint.** Only some rockets whistle. At most three booms can start in
  the same tenth of a second, so the finale is strong but not distorted.
- **Night ambience.** Soft water that rises and falls, a little moving air,
  and a far-away buoy bell now and then. It is quiet on purpose: it makes the
  two minutes of waiting feel like part of the place.

### Technical choices

- **Timing uses timestamps.** The countdown is always "next start time minus
  now". If the tab is in the background and a show time passes, one show
  plays when you come back, and the next is a full two minutes later.
- **60 fps.** Particles are capped (1800 on desktop, 1000 on phones, 500 with
  reduced motion). Trail sparks are refused first when the cap is near, so
  the main stars always appear. The static scene is drawn once and reused.
- **Trails that really end.** Trails are made by dimming the fireworks layer
  a little every frame. Dimming alone never reaches black with 8-bit pixels:
  very faint values round back to themselves and stay as a ghost haze. So
  the layer is also reduced by one brightness step sixty times a second.
  Three seconds after a burst the sky is exactly as it was before.
- **Share links hold the show, not a recording.** A show is built from one
  number (its seed) plus its colour theme, so a link only needs those. The
  theme is in the link because a show avoids the previous show's colours,
  which the person opening the link has not seen.
- **Reduced motion.** With that system setting on, shows are slower and
  sparser, there is no strobe and no white flash, and the water is still.
